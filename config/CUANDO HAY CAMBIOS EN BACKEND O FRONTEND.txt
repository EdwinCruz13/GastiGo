🔁 🔧 1. CUANDO HAY CAMBIOS EN EL BACKEND (.NET)
🧩 En tu PC
dotnet clean
dotnet publish -c Release

📤 Subir a AWS
pscp -i E:\GastiGo\config\finanzas-key.ppk -r .\bin\Release\net8.0\publish ubuntu@44.213.110.185:/home/ubuntu/api
🔄 Reiniciar servicio
sudo systemctl restart gastigo-api
🔍 Ver logs (si algo falla)
journalctl -u gastigo-api -n 50 --no-pager

🧪 Probar
http://IP/api/swagger

🎨 🔁 2. CUANDO HAY CAMBIOS EN EL FRONTEND (Angular)
🧩 Build en local

📤 Subir a AWS
pscp -i E:\GastiGo\config\finanzas-key.ppk -r .\dist\GastiGo.WEB\browser\* ubuntu@44.213.110.185:/var/www/html/
🔄 Reiniciar nginx
sudo systemctl restart nginx
