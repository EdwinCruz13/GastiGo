📦 4. RESTORE DE BD (LOCAL → AWS)
📤 Subir backup
pscp -i finanzas-key.ppk backup.sql ubuntu@IP:/home/ubuntu/
🧩 Preparar
sudo mv /home/ubuntu/backup.sql /tmp/
sudo chmod 644 /tmp/backup.sql
🧨 Restaurar limpio
sudo -u postgres dropdb GastiGoBD
sudo -u postgres createdb GastiGoBD
sudo -u postgres psql -d GastiGoBD -f /tmp/backup.sql
